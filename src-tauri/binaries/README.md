# binaries/

把 `ffmpeg.exe` 放在这里。下载来源（任选）：

- [BtbN/FFmpeg-Builds](https://github.com/BtbN/FFmpeg-Builds/releases) — 推荐 `ffmpeg-master-latest-win64-gpl.zip` 中的 `bin/ffmpeg.exe`
- [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) — essentials build

放好后，开发模式 / 打包模式都会自动加载。

体积约 80MB（已经被 .gitignore，不入仓库；发布版会随 Releases 附件分发）。
